# Blutkreislauf – Learning Nuggets (Demo)

Interaktive Lernseite für Zyklus 3 (Sekundarstufe I) mit 5 Übungen und einem Abschlusstest, dessen Ergebnis lokal im Browser gespeichert und als Textdatei heruntergeladen werden kann.

Reines HTML/CSS/JS in `index.html`, ohne Build und ohne Abhängigkeiten.
